# NEW 만료 및 검색 범위 새로고침 — 0.1.116 후보

## 변경

- 최초 `firstRegisteredAt`부터 24시간에 NEW를 만료한다. 재실행/업데이트/최근 접속으로 시간을 연장하지 않는다. 잘못된 날짜나 날짜 없는 기존 기록은 NEW를 유지하지 않는다.
- 가장 가까운 만료 시각에 로컬 타이머 하나만 실행한다. 서버 조회·삭제·폴링은 없다. 알려진 장비/확인 처리/사용자 정렬과 즐겨찾기는 보존한다.
- 검색어가 있으면 버튼을 누른 시점에 표시된 장비 ID를 고정한다. Firebase는 해당 문서만 읽고 구독하고 상태 명령을 보낸다. 검색 결과가 없으면 Firebase 요청 0회다.
- 부분 결과는 현재 목록의 대상 장비에만 합친다. 검색어 변경/중복 클릭/삭제된 대상/지연 응답/로그아웃 때문에 다른 장비를 온라인·오프라인으로 덮어쓰지 않는다. 검색어가 없으면 기존 전체 갱신을 유지한다.
- 로컬 API도 선택 ID 질의를 지원하며 기존 응답 형식과 무필터 동작을 유지한다.

## 공개 배포 차단 — 미완료

사용자가 Agent 포함 기존 정식 절차를 허용했다. 그러나 현재 체크아웃에서 실제 `change:verify:predeploy`가 실패했다.

- 루트 계약 `active`, 배포 준비 상태 아님.
- 기존 Viewer 작업표시줄 전면화, Agent 최초 전면화/파일 업데이트/실패 복구, 듀얼모니터 항목의 `physicalGap` 필드 및 확인 근거 누락.
- 과거 미커밋/미추적 테스트와 문서가 계약의 변경 증거로 인정되지 않음. 현재 HEAD는 공개 main과 다르며, 소스도 미커밋 상태.
- 기존 실제 장비 확인을 이번 NEW/검색 테스트로 대체하거나, 계약 이동·증거 삭제·상태만 변경해 통과시키지 않았다.
- 로컬 Windows 매니페스트 서명 시도는 환경변수가 가리키는 개인 키 파일이 없어 실패했다. 키를 새로 만들거나 신뢰를 변경하지 않았다. GitHub Actions에는 기존 `WONREMOTE_UPDATE_MANIFEST_PRIVATE_KEY` 비밀 항목이 등록돼 있으므로 정식 CI 경로에서 처리할 수 있으나, 현재 소스/검증 게이트부터 통과해야 한다. 키 값은 조회/기록하지 않았다.

태그 생성·커밋/푸시·CI 게시·GitHub 릴리스·Hosting 배포·자동업데이트 정책 변경·기기 설치는 수행하지 않았다. 빌드 성공과 공개 배포 완료를 구분한다. 빌드 경고는 기존 미사용 Rust 함수, SDK 도구 버전/사용 중단 API, 프런트 번들 크기 경고이며 오류는 아니었다.

## 재발 방지

`INCIDENT_REGISTRY.md`의 `INC-20261102-178`, `CHANGE_CONTRACT.json.viewerNewAndScopedRefresh20261102`에 원인/검증/남은 배포 경계를 기록했다. 상태 만료·범위 고정·요청 수·취소 및 지연 응답 검사를 유지하며, 실제 배포 조건을 낮추지 않는다.

## 같은 날 추가 승인 및 단일 모니터 실장비 결과

- 사용자가 듀얼모니터 실장비 시험을 보류하고, 단일 모니터 PC에서 문제없으면 배포하도록 명시했다. 듀얼/혼합 DPI/다중 GPU 검증은 통과로 바꾸지 않았다.
- 이 PC의 Viewer116 시험 설치는 종료 코드0, 실제 버전116으로 실행됐다. Agent116도 보호된 파일 교체 경로로 자동 재실행됐다. 장비 식별자/설정은 보존됐고, 기존 제거 프로그램은 바뀌지 않았으며 실행 페이로드9개 일치와 서버 명령 왕복을 확인했다. 다른 장비 설치나 공개 정책 변경 없음.
- 설치된116이 실제 물리 모니터1개1920×1200을 인식하고30프레임을 캡처했다. JPEG 타일 재조합 PNG를 직접 확인했으며 검은 화면/줄무늬 없이 실제 바탕화면이 표시된다. 이 내부 캡처는 네트워크 왕복·Viewer 표시나100ms 성공을 뜻하지 않는다. 좌표/키 명령 도메인16검사도 통과했다.
- Viewer는 현재 로그인 화면이다. 로그인·접속 잠금은 자동 조작하지 않고 사용자에게 직접 진행을 요청했다. 인증된 원격 화면/클릭/키보드 검증은 아직 완료하지 않았다.
- 기존 계약의 미확인 경계는 `physicalGap`에 명시하고, Markdown 증거와 추가 JSON 증거를 스키마에 맞게 구분했다. 미추적 제품 테스트/필요 보고서는 명시적으로 스테이징했으며 개인정보 백업·키·실화면은 제외했다. 사전 배포 검사는 현재 계약 `active` 상태만 거절한다. 아직 실제 접속 확인 전이므로 준비 완료로 바꾸지 않았다.
- 정상 CI에서 App TypeScript가 참조하는 기존 Functions 의존성도 설치하도록 보완했다. 서명 키·빌드 출처·게이트 조건은 유지한다. `codex/release-0.1.116`에서 준비 중이며 커밋/푸시/공개 배포는 아직 하지 않았다.
